> What is real faith? A doubting Thomas (me) crosses Christianity, Catholicism, and Buddhism —
> starting not from doctrine but from doubt and imagination, to find genuine belief.

## What's here

| Step | What |
|------|------|
| **Doubt** | Questioning unconditional doctrine (blind faith) — my name is Thomas |
| **Third view** | A perspective belonging to no single denomination — not Christianity, Catholicism, or Buddhism |
| **Dialogue** | Asking my sister, in search of real faith |
| **Asking** | Putting questions to a seminary student nephew (academic theology) |
| **Fantasy** | Re-interpreting genuine faith through imagination and fiction |

## What this repo is

Not preaching — it's the exploration **"doubt → dialogue → understanding"**.
A moving record, not a conclusion. (Reproducing the thinking, not the result.)

## What I keep

- **Never expose my sister's or nephew's identity** (name · location · photo).
- **No disparaging any religion or denomination** — the "third view" is inquiry, not exclusion.
- **No theological assertion** — always defer to "an expert must confirm".

# Helana Faith — 종교 판타지 채널

> **진짜 종교란 무엇인가.** 기독교·천주교·불교를 넘나들며, 의심하는 토마스(본인)가
> 교리가 아닌 의심과 상상(판타지)에서 출발해 진짜 신앙을 찾는 채널.

## 무엇을 하나요

| 과정 | 내용 |
|------|------|
| **의심** | 조건·이유 없는 교리(맹목 신앙)를 의심 — 이름이 토마스니까 |
| **제3의 시각** | 기독교·천주교·불교 어느 한 교단도 아닌 독립적 시각 |
| **문답** | 의심을 누나에게 물으며 진짜 신앙을 찾는 과정 |
| **묻기** | 신학대학원생 조카에게 질문 (학술 신학 접근) |
| **판타지** | 진짜 신앙을 상상·창작으로 재해석 |

## 이 레포의 성격

교리 선전(설교)이 아니라 **"의심→문답→이해"의 탐구 과정**이다.
결론이 아니라 움직이는 기록. (사고 과정 재현)

## 지킬 것

- **누나·조카 신원(이름·위치·사진)은 노출하지 않는다.**
- 타 종교·교단 비하 금지 — "제3의 시각"은 배타가 아니라 탐구.
- **신학적 단정 표현 금지** — "전문가 확인 필요"로 돌린다.
